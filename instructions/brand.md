# Product and brand notes

Edit this file to teach Claude your product's vocabulary and tone. Claude reads
it before writing narration.

## AutoSmart Audit
- What it is: a platform to plan, run and score dealership audits across a network.
- Audience: OEM network and quality teams, auditors, dealership managers.
- Tone: confident, practical, friendly. Not salesy.

## Terms (write them like this in scripts)
| On screen | Say it as | Meaning |
|---|---|---|
| Center | center | a dealership or outlet being audited |
| Evaluation cycle | evaluation cycle | an audit round, e.g. a quarter |
| SE Q3 | Standard Evaluation, Q three | cycle short names |
| CXE | Customer Experience Evaluation | |
| MDSA | monthly self-audit | Monthly Dealership Self Audit |
| PIC | person in charge | dealership staff who fix issues |
| Platinum / Gold / Silver / Bronze | as written | score bands (90+, 80+, 70+, below 70) |
| Preview & Submit | Preview and Submit | final review before submitting |

## Always / never
- Always say "centers", not "dealers", unless the screen says otherwise.
- Never mention competitor names.
- Never promise features that are not shown in the recording.
